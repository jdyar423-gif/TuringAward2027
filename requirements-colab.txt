#
# jax, jaxlib and libtpu are NOT listed: the run uses the jax the TPU runtime ships with. The
# notebook installs this file with a constraints file that holds jax, jaxlib and libtpu at their
# installed versions (pip fails instead of replacing them) and checks the versions afterwards:
#
#   pip freeze | grep -iE '^(jax|jaxlib|libtpu)==' > constraints-jax.txt
#   pip install -r requirements-colab.txt -c constraints-jax.txt
#
# Versions are those the code was tested with (Python 3.13). llama-cpp-python has no wheel on
# PyPI for 0.3.37: pip builds it from source (cmake and a C++ compiler; 5 to 15 minutes; set
# CMAKE_BUILD_PARALLEL_LEVEL to the core count to speed it up).
