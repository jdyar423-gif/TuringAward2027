## 2. 由量測導出的設計

量測二、三是同一條定律的兩面：**越稀有的詞，私有記憶對它越值錢，寫它的列對別的東西越沒有影響。** 共享的稠密核心按梯度質量分配容量，稀有的東西分不到；而稀有的東西出現在很少的文字裡。

> 稠密算共性，稀疏記個性；清醒時只寫稀有，睡眠時才動稠密。

**定理 1（精確局部性）。** v9 的參數是 θ =（稠密 θ_D，逐詞列 r_v），r_v 含輸入嵌入、逐圈 ve、輸出增益、頁的鍵與值（每個詞 9,472 個數字）。模型在輸入 x 上的輸出只經由 x 裡出現的詞讀到 r_v，所以只改動列集合 S 的更新 Δ 滿足 tok(x)∩S = ∅ ⇒ f_{θ+Δ}(x) = f_θ(x)，逐位元。
- 推論 1a（干擾界就是詞頻）：長 |x| 的不相干文字被影響的機率 ≤ |x|·Σ_{v∈S} f_v。量測三：0.00105 × 約 80 token = 8.4%，實測 5／60 = 8.3%。
- 推論 1b（交換律）：列集合互斥的寫入可交換、互不覆蓋。實測 1.004 → 1.004。
- 推論 1c：要以最小干擾學一段文字，就寫它裡面詞頻最低的詞的列——稀疏記憶微調（arXiv 2510.15103）的選列規則在以詞表為鍵的記憶上是導出的。
- 輸出嵌入對每個詞都稠密，不在可寫集合裡（arXiv 2610.09835 指出遺忘集中在那裡）。

**定律 2（價值隨稀有度上升）。** 量測二的表。它修正 `docs/V9.md` 的單一定律 dL = −c·E ln(n(x)/n₀)：n₀ 隨詞頻下降，同樣 8 個私有神經元對稀有詞每次出現的價值是常見詞的 4–9 倍；每個數字的價值則相反，兩者的乘積決定水位線。

**定理 3（讀取的統一：對殘差的核回歸）。** 在鄰居 (c_i, y_i) 上以步長 η 更新參數子集 S，一階下查詢語境 c 的 logit 改變量是 Δz(c) = η Σ_i Θ_S(c, c_i)(e_{y_i} − p_i)，Θ_S = J_S(c) J_S(c_i)ᵀ。S＝輸出頭時 Θ 是隱狀態內積（kNN-LM）；S＝逐詞列時 Θ 只在兩段文字有共同詞時非零；S＝稠密時是完整的切核。量測四的排序是逐詞列核 > 稠密核、輸出頭核，三者都 ≤0.05 nats；逐字重用（0.66–0.80）遠大於它們。所以重用靠語境與候選帶，學習靠稀疏列，「回答前向鄰居學習」不當主槓桿。

**定理 4（閉式的最小干擾寫入；要驗證，不是已證實的效果）。** 頁在一個位置的輸出是 u = Σ_j φ_j·val_j（φ ∈ ℝ⁸）。要讓它改變 Δu 並對該詞平常的語境擾動最小：min tr(ΔVᵀCΔV) s.t. φ*ᵀΔV = Δu，C = E[φφᵀ]，解為 ΔV = C⁻¹φ*·Δuᵀ ∕ (φ*ᵀC⁻¹φ*)：每個位置一個 8×8 線性系統（ROME 的秩一公式放進單一詞的私有鍵空間）。

**命題 5（統一水位線）。** 不活躍的數字有兩種用途：稀有詞的頁列與寫入的問答。照開跑前的曲線，拿掉排名 ≥5120 的 3,072 個詞的頁與增益（出現次數的 5.1%，+0.025 nats，未共同適應的上界）釋出 23.6M，加上 v9 原有的 1.96M 空位，可放約 44% 的藏書（約 17.6 萬則）。ve 每個數字的價值是頁的 20 倍以上，不動。**最終的 K 在續訓後的權重上重量一次、與開發集評審一起決定**；晶片上訓練的是完整的 v9。

**命題 6（睡眠訓練的就是部署任務）。** 留一法檢索訓練的相近度分佈與開發題相同（量測五），六小時訓練的任務分佈就是推論時的任務分佈。

## 4. 晶片上的執行（`configs/m6v.py`）

- **模型**：`configs/v9.py` 原封不動（98,036,104 個數字，每 token 讀 19,631,240），執行設定是 24 小時那次最後用的：`take` 表梯度、每微批次 16 列切四塊、加速開關 `kernel=onetile:save relu2=1 ce=0 flat=1 rows=1 tokn=1`。晶片上沒有新的計算圖。
- **起點**：`run.init_from = release/main16-v9-before-dpo`，全部 64 個葉節點（`bes/train/init_from.py`；最佳化器狀態重建）。
- **資料**：`configs/m6.py` 的六小時資料流（對話 90%→95%、教師寫的來源、留一法範例、事後計算機標註、評測題剔除、2,048 token 列、最後 15% 只對助理 token 算損失）。訓練用藏書全量（399,699 則）。
- **學習率**：把兩段訓練當成一次 T₀＋T₁ = 1.36×10¹⁰＋3.7×10⁹ token 的訓練：24 小時的規則（峰值後線性降到 0.1 倍）在續訓起點是峰值的 1 − 0.9·T₀/(T₀＋T₁) = 0.29 倍、終點 0.1 倍。`lr_mult` 0.29、`final_lr_frac` 0.34、矩陣群的資料因子把 `tokens_before` 算進去：矩陣學習率 0.00162 → 0.00055（24 小時那次是 0.00611 → 0.00061）。前 2% 升溫。
- **量**：v9 在這顆晶片上約 19.7 萬 tok/s；訓練約 313 分鐘、約 3.7×10⁹ token。之後 DPO 12 分鐘（學習率 3×10⁻⁶）、匯出（不含藏書）；DPO 前的權重保存。
- **時間表**（≤20,735 秒）：開機約 6 分 → 訓練約 313 分 → DPO 12 → 匯出 2 → 緩衝 2 → 取回並歸還 7；預算守衛提前 150 秒強制歸還。每 15 分鐘檢查點並取回快照；被收回就以快照續訓，剩不到一小時則在 CPU 上從快照匯出。

**開跑門檻**（全部通過才請求 TPU）：(a) 本機 `configs/m6v_smoke.py` 兩段全流程（第二段由第一段的匯出起跑）；(b) Colab CPU 執行階段上 `configs/m6v_rehearsal.py`（真模型、真權重、小批次）：分片在新機器上解開、64 個葉節點載入、第一個訓練損失是訓練過的模型的水準、檢查點續訓、DPO 與匯出完成；(c) 單元測試。晶片上第一個日誌點的損失若不像訓練過的模型（從零訓練在第 50 步是 3.5），立刻停下歸還。

## 5. 可否證的主張（結束時逐條回報）

1. 定理 1：不含被寫詞的輸入，寫入前後回覆逐位元相同（測試強制）。
2. 推論 1a：受影響比例與 |x|·Σf_v 在抽樣誤差內一致（續訓後的權重上重量）。
3. 定律 2：續訓後的權重上，每次出現的價值仍隨排名單調上升。
4. 續訓：對話保留集損失低於 1.564；網頁保留集損失不高於 2.774＋0.05。
5. 命題 5：被淘汰的列實際造成的損失不超過續訓後重量的上界。
6. 定理 4：閉式寫入在量測三的同一組測試上，換句話問的損失與生成答對數都不輸梯度寫入，否則不採用並照實回報。
7. 整體：測試集 200 題只跑一次，對 Falcon 官方設定，登記評審兩種順序與精確分數；藏書開／關、各類別、K=1、續訓前後。

## 6. 誠實的界線

- **前人的**：稀疏記憶微調、ROME、推論時訓練（arXiv 2305.18466、2410.08020）、kNN-LM、互補學習系統、水位線配置。**這裡新的**（就我所知）：定理 1 在以詞表為鍵的記憶上是精確的、可逐位元檢驗的；干擾界等於詞頻並與實測相符；價值—稀有度定律與它對 `docs/V9.md` 單一定律的修正；頁列與寫入條目的統一水位線；以及這些在同一個模型上的量測。夠不夠格由第 5 節決定。
- **開跑前的負面結果**：回答前向鄰居學習只有 −0.05 nats；列寫入之後的貪婪生成只答對 1–3／8。所以「教一次就記得」由文字條目保證，列寫入是要量的研究項，不承諾。
- **不做的**：改 v9 的張量形狀（例如加寬 ve——量測一顯示它是每個數字最值錢的表，但六小時內改圖的風險不值得）；把藏書用模型自己編碼；在晶片上做任何沒彩排過的事。
- **預期**：v9 的保留集損失已與 Falcon 的推估值相當（2.33 對 2.36；後者是專案縮放律的推估，不是實測），差距在對話行為。本輪加約 3.4×10⁹ 個教師對話 token，並把教師原文的重用接上去。預期明顯優於 24 小時模型，對 Falcon 接近到領先；沒有相近條目的題（寫作、數學推理）仍是弱項。「遠超」不保證，照實回報。

- **範例帶標籤**：每個範例的第一行寫明它與使用者問題的相近程度（close／similar／loose／other numbers；`data.exemplar_tag`、`decode.exemplar_tag`）。起因是量到舊模型會不分遠近地照抄範例。
