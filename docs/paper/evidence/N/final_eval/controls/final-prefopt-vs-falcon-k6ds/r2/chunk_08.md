----- REPLY A -----
Certainly! Below is a Python function that converts a temperature from Celsius to Fahrenheit. The formula to convert Celsius (°C) to Fahrenheit (°F) is:

\[ F = \frac{9}{5} \times C + 32 \]

Here's how you can implement this function:

```python
def celsius_to_fahrenheit(celsius):
    """
    Converts a temperature from Celsius to Fahrenheit.

    Args:
        celsius (float): The temperature in Celsius.

    Returns:
        float: The temperature in Fahrenheit.
    """
    return (9/5) * celsius + 32

# Example usage:

fahrenheit_value = celsius_to_fahrenheit(celsius_value)
print(f"The temperature in Fahrenheit is: {fahrenheit_value}")
```

- **Formula:** It multiplies the Celsius temperature by \( \frac{9}{5} \) to convert it to Fahrenheit, then adds 32 to shift the midpoint between 0 and 180.
- **Return Value:** The function returns the converted Fahrenheit temperature.

Here's a Python function that calculates the n-th triangular number:

```python
def triangular_number(n):
    """
    Calculate the n-th triangular number, which is the sum of the first n natural numbers.
    
    Args:
    n (int): The position of the triangular number in the sequence.
    
    Returns:
    int: The n-th triangular number.
    """
    if n > 0:
        return n * (n + 1) // 2
    else:
        return 1

# Example usage:

print(triangular_number(n))  # Output: 6
```

2. It checks if `n` is greater than 0. If so, it returns `n * (n + 1) // 2` because the `n`th triangular number is the sum of the first `n` natural numbers.
3. If `n` is 0, it returns 1 as the sum of the first 0 natural numbers is 0.
4. For all other values of `n`, it returns 1, as this is the base case of the triangular number formula.

This function is efficient for small values of `n` (up to 10) and works correctly for any valid input.
