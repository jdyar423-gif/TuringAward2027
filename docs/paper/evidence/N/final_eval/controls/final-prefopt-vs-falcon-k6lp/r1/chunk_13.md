What is a Python generator?

----- REPLY A -----
A Python generator is an object that provides an interface for creating generators, which are functions that yield (return) items from their current state. Generators are particularly useful for processing sequences of data in a concise and memory-efficient manner. Here are some key features and characteristics of generators:

### Key Features:
1. **Memory Efficiency**: Generators generate items on-the-fly without needing to store all items in memory at once. This is especially beneficial for large datasets.

2. **Conciseness**: Generators produce values on the fly, making the code more readable and easier to understand.

3. **Lazy Evaluation**: Generators are lazy, meaning they only yield items when needed. This is useful for processing small parts of a larger data flow.

4. **Customizable**: Generators can be customized with various parameters to control behavior, such as the number of iterations, yielding options, and other options.

### Example Usage:

```python
def fibonacci(n: int) -> int:
    """Generate Fibonacci numbers up to n."""
    a, b = 0, 1
    for _ in range(n):
        yield a  # Yields first n numbers
        a, b = b, __futureimeplace(1, a+b)  # Yield b each time

# Example usage
for i in fibonacci(10):
    print(i)
```

### Benefits:
- **Ease of Use**: Ideal for small to medium-sized datasets.
- **Flexibility**: Supports various data processing needs.
- **Concurrency**: Can be used with generators to process multiple tasks concurrently.

Generators are a powerful tool in Python for building flexible and efficient data processing pipelines.

def binary_search(sorted_list, target):
    low, high = 0, len(sorted_list) - 1
    while low <= high:
        mid = (low + high) // 2
        if sorted_list[mid] == target:
            return mid
        elif sorted_list[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
