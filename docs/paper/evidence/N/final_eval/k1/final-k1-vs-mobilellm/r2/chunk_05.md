Write a Python function that returns the number of vowels in a string.

----- REPLY A -----
```python
def count_vowels(s):
    vowels = {'A', 'E', 'I', 'O', 'U'}
    count = 0
    for c in s:
        if c in vowels:
            count += 1
    return count
```
