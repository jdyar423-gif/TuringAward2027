
```python
# Original list
my_list = [1, 2, 3, 4, 5]

# Reverse the list using a loop
reversed_list = []
for num in my_list:
    reversed_list.append(num)

print("Original list:", my_list)
print("Reversed list:", reversed_list)
```

**Output:**
```
Original list: [1, 2, 3, 4, 5]
Reversed list: [5, 4, 3, 2, 1]
```
