### P.2 範式

表 P2 與表 P3 是同一件事的兩面。詞越稀有，私有記憶對它越值錢，寫那份記憶時碰到別的東西也越少，而且原因相同：共享的核心服務的是共性，稀有的東西只出現在很少的文字裡。

> **稠密的核心算共性，稀疏的列記個性。清醒時只寫稀有的，睡著時才動稠密的。**

訓練結束就把模型凍結，或者微調它全部的權重，都違反這條規則；把一部分記憶以詞表為鍵的配置則可以精確地遵守它。同一條軸上再往外一格是只出現過一次的東西——發生過一次的一整段問答：那用文字寫下來。

### P.3 精確的局部性

**定理 1。** 設參數由稠密的葉節點與每個詞表 id `v` 在各逐詞表裡的一列 `r_v` 組成（`emb/tok`、`emb/ve`、`gain/o`、`page/key`、`page/val`：每個
id 9,472 個數字）。輸入 `x` 的前向計算只會讀到 `x` 各位置上的 id 的 `r_v`。因此，對任何支撐集是集合 `S` 的列的改動
`Δ`：若 `x` 沒有任何 token 屬於 `S`，改動後在 `x` 上的輸出與改動前逐位元相同。

*推論。*（a）長 `|x|` 個 token 的文字被碰到的機率至多是 `|x| Σ_{v∈S} f_v`：以表 P3 第一列的被寫列（總詞頻 0.00105）與約 80 個 token
的文字算，上界是 8.4%，而 60 篇裡有 5 篇（8.3%）含被寫的詞。（b）兩次寫入在「彼此教的文字都不含對方寫的詞」時精確可交換；表 P3
的前兩列是它的結果（寫其他七個事實時，一個事實的損失不動）。（c）要干擾最小，該寫的是被教文字裡最稀有的詞的列：稀疏記憶微調的選列規則，在以詞表為鍵的記憶上是推論，不是經驗法則。輸出嵌入對每個詞都是稠密的，不在這個意義下可寫。

這條定理由測試強制執行（`tests/learn/test_row_write.py`）：經由 `bes.learn.write` 的寫入只改到交給它的列；不含被寫詞的輸入，寫入前後的 logits
是相同的陣列；只與被教文字共用「沒被寫」的詞的輸入也相同；文字互不相干的兩次寫入，先後次序對調得到相同的參數。

### P.4 寫哪張表，朝哪個方向

登記的計畫裡有一個閉式的寫入（它的定理 4）：在「對被教文字的一階收益固定」的所有頁值改動裡，對這個詞其他語境的頁輸出擾動最小的，是以它八個私有神經元啟動的二階矩 `C = E[s sᵀ]`
白化過的梯度。實驗（`lab/m6v/theorem4.py`，三輪）對每個詞在至多 24 則藏書條目上記錄這些啟動，以有、無白化兩種方式寫入表 P3 的八個事實，並加上表 P3
沒有的兩項量測：*同詞語境*（含被寫詞、沒用來估統計量的藏書條目，每個詞至多六則）與*自然語境*（在含被寫詞的條目裡隨機抽 150 則，詞依實際出現的頻率計）。

*寫哪張表比朝哪個方向重要。* 只寫頁值而不是五張逐詞表全寫（排名 512 以後的列）：換句話問的損失 0.65 對 0.58，60 篇不相干文字的漂移 +0.002 對
+0.026，同詞語境的漂移 0.027 對 0.080，貪婪回覆都是 8 題答對 3 題；寫每個內容詞時是 +0.154 對 +0.827。頁值是唯一既私有（定理
1）又受語境閘控（私有神經元）的列；嵌入或逐圈 value embedding 一改，那個詞的每個語境都跟著變。所以 `bes.learn.write` 預設只寫頁值。

有一件事任何寫法都沒有改變：自由生成時，寫進去的事實至多八題答對四、五題，而且只有在連常見詞的列也寫的時候，而那樣寫會賠上別的一切。要逐字記得的東西，用文字寫下來（P.6）。

### P.7 鬆散範例與相近程度標籤

表 P7 的分界決定了開跑前的最後一項改動。藏書自己的門檻（排名分數 0.5；算術訊息 0.75；數字、專名、次序、程度、肯否定任何一項對比都排除條目）給 200 題開發題裡的 83
題範例，30 題算術題裡只給 1 題。分數在 0.35 與 0.5 之間的候選，約三分之二是同一類任務、內容不同（另一個價格的折扣、另一個主題的俳句、另一個城鎮的成長）；而算術題最好的候選因為數字不同被排除，那正是它們之所以是例題的原因。

*鬆散模式*（`AnswerLibrary.exemplars(floor=…)`）：最佳範例的分數可以低到門檻，不分訊息種類；對比檢查做到門檻為止；與訊息只有數字不同、其餘皆同的條目可以入選。門檻 0.35
時它給 148 題開發題範例（算術 28、寫作 23、指令 30）。不給門檻時藏書的行為與原來逐位元相同，逐字回覆的規則沒有動。

*相近程度標籤。* 問一件 120 美元、打 65 折的外套，看到的例題是 200 美元、打 85 折，一日訓練的權重就回答 200
美元的那一題；要一個關於存錢、用雙角括號包起來的標題，旁邊的範例是生產力的標題，它就把生產力的標題交出來。它學到的是「`LIBRARY`
那一輪裡有答案」，而讀那一輪的人看不到索引的分數。所以每個範例以檢索算出的一行開頭（`match_tag`）：`Match: close`（分數不低於
0.7）、`similar`（不低於藏書的門檻）、`loose`（低於門檻；訓練裡的干擾範例也帶這個標籤）、`other numbers`。

*在一日訓練的權重上量*（沒有標籤、從沒為此訓練；門檻 0.35 時範例會改變的 79 題開發題，77 題有判讀）：依分數入選的條目讓這些題目由 0.383 升到 0.436（7
題變好、3 題變差），只有數字不同的條目由 0.383 降到 0.283（3 題變好、7 題變差：例題的數字被照抄）。合到整個開發集：藏書門檻
0.4775、鬆散模式只依分數 0.4900、連數字不同的也用 0.4750；差別都不顯著。

*訓練時*（`configs/m6v.py`）：每個樣本以機率 0.6 用門檻 0.35 的鬆散模式，其餘用藏書的門檻，一律帶標籤。在 1,000 則藏書問題上（留一法），有範例的樣本由 48% 升到
65%，全部樣本的 11% 帶著分數低於 0.5 的範例，一個樣本由 420 個 token 增為 467
個。因為兩種模式都在訓練分佈裡，推論的門檻是事後在開發題上做的選擇（P.9），藏書自己的門檻是退路。

### P.8 續訓

這次執行（`configs/m6v.py`）由一日訓練在偏好最佳化之前的 64 個葉節點出發，最佳化器狀態重建，計算圖與加速方案與一日訓練相同，學習率把兩段訓練當成一次來排（原峰值的 0.29
倍，線性降到 0.099 倍）。它訓練了 13,615 步、每步 2,048 個 token 的列，共 3.57 × 10⁹ 個 token，用 19,004 秒，每秒 188,300 個
token，沒有重啟；資料流九成是對話，每個樣本帶著藏書在留下它自己那一則時會給它看的範例（P.7）。之後是 578 秒的偏好最佳化（通過執行自己的驗收：1,823
組保留的偏好對，準確率 0.500 → 0.690）與匯出。連同先前用掉的 865 秒，這項任務用了給它的 21,600 秒裡的 20,937 秒。

### P.9 續訓後的讀者怎麼用藏書，以及讀者自己的檢驗

*續訓後的模型不再照抄。* 執行到四分之一時的快照（第 3,241 步）做成同樣的出貨形式、同樣判讀，開發題是 0.465，續訓前是 0.477：沒有範例的題目變好了（0.397 → 0.436；16
題變好、8 題變差），有範例的題目變差了（0.556 → 0.465；5 題變好、18 題變差，p = 0.011；其中有範例的對話題由 14／3／12 變成
4／6／19）。讀回覆就知道原因。問怎麼判斷雞蛋新不新鮮，旁邊放著同一個問題換了說法的藏書答案，一日訓練的權重把藏書的文字交出來（放進水裡，沉底平躺就是新鮮）；續訓後的模型自己寫五點條列，而且寫錯。留一法檢索（P.7）從不把一則條目放在它自己的問題旁邊，所以訓練裡每一個範例都是*別的*問題的答案，模型學到的正是這件事。對損失來說這是對的，對讀者來說是錯的：教師的文字比
2,000 萬活躍參數寫的好。鬆散範例也沒有幫上忙（它會改變的 79 題：0.405 → 0.411），不過帶了相近程度標籤之後，只有數字不同的例題不再害它（3 題變好、3
題變差；續訓前是 3 與 5）。

*於是問題由權重移到決定：什麼時候可以把藏書的答案原樣交出去？* 藏書自己的規則（同一個問題、幾乎逐字）在 200 題開發題裡只取 12
題。索引的字詞重疊分不出「為什麼冰浮在水上」與「為什麼油浮在水上」，也認不出換了說法的同一個問題。這件事可以直接問讀者。對藏書條目（q_e, a）與使用者的問題
q，模型對同一段答案做兩次教師強制的前向（各放在只有兩輪的對話裡），得到 a 的每個 token 的 d_t = log p(a_t | q_e, a_<t) − log p(a_t | q,
a_<t)：使用者的問題讓這個 token 付出的代價。檢驗有整體與局部兩部分（`bes/decode/fitness.py`）：

    fit    = − mean_t d_t                       整段答案在 q 下與在 q_e 下一樣可能        （fit ≥ −τ）
    window = max_t (d_t + d_{t+1} + d_{t+2})     沒有哪三個連續的 token 在 q 下不可能      （window ≤ w）

減去「在原本問題下」的那一次前向，才讓不同的答案可以比較（一句事實與一首詩的機率差很多，各自與自己比）；單看答案在使用者問題下的機率什麼也預測不了（AUC
0.57）。局部的那一部分是因為平均值看不到決定性的那一個詞：「*break the ice* 是什麼意思」旁邊那段 *break a leg* 的解釋，三百個 token 裡只有三個不可能，平均值是
−0.05 到 −0.07。這是計畫的定理 3 從另一面讀：決定什麼算「相近」的核可以是字詞重疊，也可以是讀者自己的條件機率。
