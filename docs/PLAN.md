# 計畫 v6：三尺度貝氏機（BES-100M-A20M）——後驗＝先驗×證據，在三個尺度上精確計算

## 1. Context

- 目標不變：總參數 ≤100M、每 token 活躍 ≤20M，單顆 TPU v6e（Colab v6e-1）一次 24h 內訓練完成，盲測體感勝過 Falcon-H1-Tiny-90M-Instruct 與 MobileLLM-R1.5-140M。倉庫為空，分支 `claude/modest-carson-yi2d9g`，不開 PR。我碰不到 TPU：交付程式碼＋Colab notebook＋runbook，能在本容器驗證的全部驗證。
- 研究歷程：累計 8 個 Opus 5.5 Max workflow、30 餘次代理執行，加上我自己的推導與數值實驗。
- v5 被退回的理由是「底層架構不夠創新」。這一輪我直接動底層原語，做了三件事：
  1. **推導並檢驗「精確貝氏注意力」**（把 softmax 注意力換成語境內的高斯過程後驗）。數學成立，但公平對照、真實文本、取樣行為與 TPU 成本四項檢驗都不支持把它當核心（§3 尺度一）。
  2. **推導並檢驗「尺度遞迴迴圈」的圈數配置律**。配置律成立，但代入實測縮放律後增益只有 0.1–3%。
  3. **把同一個原理推到輸出與整段回覆兩個尺度**，得到一個貫穿全機的結構：後驗＝先驗×證據。
- 本版相對 v5 的實質改動：(a) 每個注意力頭加上**校準匯點與信心通道**（精確的計數收縮，零成本）；(b) 主機精確計算的**語境內 n-gram 計數頭**，帶冪律（Pitman–Yor）統計量；(c) 整段回覆尺度的 **Feynman–Kac 解碼**（少量粒子＋精確勢函數）；(d) 記下所有被否定的候選。v5 的藏書、暫存器與訓練配方保留。

## 3. 原理與數學：一個原理，三個尺度

**原理**：模型的每一步都是「後驗 ∝ 先驗 × 證據」。先驗是 20M 活躍參數學到的平滑規律；證據是語境、藏書與精確演算法給的東西。能精確算的就精確算，不能的才交給網路或粒子。下列每條都有證明或數值複核，並經對抗審稿修正。

### 尺度一：層內——注意力是語境內估計

| # | 命題 | 狀態 | 後果 |
|---|---|---|---|
| B1 | **帶匯點的 softmax 注意力是精確的貝氏估計**：在「局部常數」模型下它就是後驗均值；鍵為精確匹配時恰為 Dirichlet 後驗預測 (n_ab+λ/V)/(n_a+λ)，匯點 logit＝β+log λ。非匯點的總權重 n/(n+λ) 就是信心 | 已證；數值誤差 1e-16（文獻 2026 已證前半） | 每個頭加一個可學 logit 的匯點（值＝可學先驗向量），並在值向量附一個常數 1 通道，免費讀出信心 |
| B2 | **精確高斯過程注意力**：一次 Cholesky 分解給出所有前綴的後驗均值、變異與證據；「誘導點＋近期視窗」的區塊版同樣精確。恆等式 w_GP − w_sink = A⁻¹((1ᵀc)c − Gc)/(λ+1ᵀc)：兩者相等當且僅當 Gc=(1ᵀc)c；匯點 softmax 恰是「常數核（所有鍵完全相關）＋隨查詢而定的雜訊 λ/c_j」的高斯過程。GP 頭的固有性質是不稀釋（強匹配不被大量弱鍵沖淡）與不被重複鍵佔滿 | 已證並經審稿複核；7e-16 | 見 B3 |
| B3 | **判決：不採用 GP 頭。** 公平對照（對手是匯點 softmax）只好 0.3–0.5%；文獻同族方法為 0.1–1.6%；真實文本上 Dirichlet 式收縮只值 ≤0.008 nats；溫度 ≤0.8 取樣時迴圈更多且成為吸收態（τ=0.6：63.6% 對 5.0%）；TPU 成本為 softmax 頭的 4.5–9 倍、吞吐降 17–37% | 四個獨立檢驗一致 | 它唯一的優勢是對「重複出現的近似誘餌」穩健，不值這個成本 |
| B4 | **語言是冪律的**：語境內快取的最優收縮是 Pitman–Yor 折扣，需要「不同後繼的種類數」K；在真實文本上比固定權重好 0.025–0.048 nats（512 token 之後 0.056–0.098），Dirichlet 與 GP 形式都表達不了 | 真實文本實驗 | 由主機精確計算 1–3 階的 n-gram 計數頭，輸出 (n, n_b, K) 與後繼嵌入；文獻中硬接線的 n-gram 頭在 340M 模型上 −6.7% 困惑度 |

### 尺度二：輸出——先驗×局部證據，精確歸一

| # | 命題 | 狀態 | 後果 |
|---|---|---|---|
| T1 | 候選集 U 的價值是粗化後的 KL：任意加性信任度的增益 = KL(P_U‖Q_U) − KL(P_U‖Q′_U)，損失對信任度為凸；看不見可靠度變數 R 的信任度恰損失 I(R;Z) | 已證；1e-15 | 候選零初始化、可逐型別關閉；相關性特徵的價值可計價 |
| T2 | 複製是跑在網路之上的 LZ77：指認來源恰付 log₂(M/occ) 位元，極小極大意義下不可避免；檢索預付其中 log₂(M/M_ret)。最優信任度對匹配片段上的累積驚奇為仿射，於離開風險處飽和 | 已證（需相對「已讀段落的網路」計值） | 信任頭的輸入特徵；出現次數只在取回的段落內計 |
| T3 | 歸一化用補集形式的 log-sum-exp。傾斜恆等式 lse(z+S)=lse(z)+log1p(Σ softmax(z)_v·expm1(S_v)) 代數上正確，但 fp32 下抵消誤差可達 0.013 nats，被允許質量極小時會得到 −inf | 數值 | 恆等式只當測試 oracle |

### 尺度三：整段回覆——Feynman–Kac 路徑測度

目標分佈 π(x) ∝ p(x)·∏_t g_t(x_{≤t})·Φ(x)：p 是網路，g_t 是主機給的精確勢函數（圍欄/括號未關不得結束、明確的句數/項數/字數、算式後的數字必須等於求值結果），Φ 是整段品質。偏好優化想把 π 蒸餾進權重；20M 活躍參數裝不下的部分，可以在推論時用粒子算。

| # | 命題 | 狀態 | 後果 |
|---|---|---|---|
| F1 | 序列蒙地卡羅（含依有效樣本數自適應重取樣）對歸一化常數的估計無偏 | 已證（標準） | 粒子法是對 π 的一致取樣器 |
| F2 | 對 token 局部的硬約束，局部最優提議的增量權重恰為「被允許的機率質量」；貪婪遮罩取樣的不是條件分佈。主機強制寫入的工具結果例外：純遮罩就是正確取樣，加權只增雜訊 | 已證 | 約束用加權粒子；算式結果直接強制 |
| F3 | 最優扭轉函數是 log E[e^{R/τ} \| 前綴]，必須以相鄰兩步的比值進入（當成每步勢函數會重複計值）；權重變異取決於它對兄弟 token 的相對誤差 | 已證 | 評分頭的訓練目標與用法 |
| F4 | **極限**：每個重取樣階段至多把分佈傾斜 log K − (K−1)/K nats（K=8：1.20；K=32：2.50）；重要性取樣需約 e^{KL} 個粒子；選擇永遠贏不過 pass@K；評分誤差厚尾時增益對 K 非單調 | 已證＋模擬 | 用小 K；粒子與偏好優化互補而非替代 |
| F5 | 對可由有限自動機表示的約束，Doob 扭轉可在代理的馬可夫模型上精確算出；扭轉的每步對數誤差為 s 時，T 步回覆的 Var(log Ẑ) ≈ 1.2·T·s² | 實驗（n-gram 替身，真實文本） | 約束的前瞻用精確表；學習式評分頭只在誤差夠小時才用 |

### 時間與記憶（沿用 v5，已依審稿修正）

- **時間**：在迴圈律 N_eff = N₁ + r^φ·N_R 下，活躍預算全給迴圈核心最優；固定訓練 FLOPs 時 r*≈8–17（r=8 起步，試 12）。
- **記憶**：24h（約 2.6e10 tokens）內任何架構都只學得會約 7 萬–68 萬條事實（曝光下界）；帶價 MDL 相位定理給出「不存→書寫→計數→訓練」的單調次序；無關探測坍縮說明多出的 80M 只有透過隨輸入而定的位址才有價值。

### 被否定或降級的候選（照實列出）

精確 GP 注意力（B3）；「貝氏頭能抑制重複」（相反：精確貝氏預測會認可迴圈，需降低自我生成證據的權重）；尺度遞迴迴圈（配置律 R_b ∝ (E_b/w_b)^{1/(1+αφ)} 成立，增益僅 0.1–3%）；粗到細輸出頭（即 SVD-softmax，打平）；自編碼藏書（各部分有前例，經典壓縮器免費位元精確，僅列延伸實驗）；「迴圈買不到知識」（不成立）；以相似性搜尋下界否定學習式路由（下界在我們的預算下不綁定）；「粒子讓活躍參數上限不再限制傾斜」（只對一半：受 log K 限制）。

## 4. 架構

```
使用者輪 ─► 主機精確層：暫存器、約束編譯、n-gram 計數頭、(門控)檢索 ─► [藏書段落 ≤160 tokens] + 對話
e = RMSNorm( E_in[x] + 暫存器嵌入 + W_n·[n-gram 後繼嵌入, 計數特徵] )             通道 ℓ=(e,e)
for r = 1..8:  u = α_r·ℓ ;  s = RMSNorm_r( Block_B(Block_A(u ; VE_r[x])) ) ;  ℓ = M_r·ℓ + β_r⊗s
      每個注意力頭：softmax 於 [語境鍵 ∪ 匯點]，值的最後一維恆為 1 ─► (估計, 信心)        〔尺度一〕
h = Σℓ ─► RMSNorm ─► P(768→512) ─► E_out(8192×512) ─► z（fp32）
p = softmax( z + Σ_k b_k·onehot(cand_k) )     計算片段 <<expr= 由主機求值後強制寫入     〔尺度二〕
整段回覆：K 個粒子 × 精確勢函數 ─► 剔除失敗樣本 ─► 長度帶內共識選擇                     〔尺度三〕
```

**A. 技能引擎（全部活躍）**：byte-level BPE V=8,192；d=768、2 個共享區塊、6 頭×128、FFN 3072（ReLU²）、固定 r=8、雙通道 hyper-connection、RoPE＋QK-norm、分解式輸出頭秩 512、softcap、logits 全程 fp32；T=1024，最後三分之一與對話階段 T=2048。
- **校準匯點與信心通道（B1，新增）**：每個頭一個可學 logit 的匯點（用 splash attention 的 `sinks` 參數，或保留一個不經 RoPE 的維度實作）與一個可學先驗向量 m0；值向量保留一維恆為 1，輸出的該維即非匯點質量。頭的輸出＝注意力結果＋(1−信心)·m0，信心另送進輸出投影。不改變張量形狀，不增加計算。
- 免費小技巧（短因果卷積／遮 BOS 的 smear、每頭輸出閘、殘差純量、backout、QK-gain）經 E2 消融後才加入。

**B. 精確鍵表**：輸入嵌入 8192×768；逐圈 value embedding 8×8192×128（寬度由嚴格口徑決定；E2 另量 512）。

**C. n-gram 計數頭（B4，新增；主機 NumPy，全語境）**：對每個位置、1–3 階，取「先前出現過同一 n-gram」之後的後繼統計：總次數 n、前 4 個後繼及其次數 n_b、不同後繼的種類數 K。進入模型的是後繼嵌入的加權和與 (n, n_b, K) 的分桶嵌入，網路可由此實現 Pitman–Yor 折扣。來自模型自己已生成文字的證據單獨計數並降權（實驗顯示 ×0.25 可消除它誘發的迴圈）。

**D. 知識庫（書寫，不經梯度）**：Simple English Wikipedia 為主（清理後）＋依重要性挑選的英文維基首段＋緊湊事實層（QA 對與三元組）；64KB 獨立 xz 區塊，60M 個數字 ≈ 338MB 原文；計入總量的截斷索引約 4M 數字。**門控**：只在 BM25 分差、標題吻合與查詢型別都過門檻時取 1 段（≤160 tokens），放在使用者輪之前，後續輪次丟棄。複製候選只來自使用者輪與當前段落，信任頭依 T2 取特徵並封頂；逐字複製超過 8–12 tokens（名稱、數字、引文除外）在解碼端攔下。選書用成本效益貪婪。

**E. 精確狀態與諭示**：整數暫存器（角色、圍欄/引號奇偶、括號深度、字/句/行/項計數、倒數）進入殘差與額外的 RoPE 時鐘（核心外套用）；約束編譯器把提示中的明確數量與格式轉成倒數暫存器與勢函數；計算片段由白名單 AST 精確求值後強制寫回。

**F. 輸出律**：稀疏候選以加性偏置併入 logits，在分塊交叉熵內 compare-select 還原後直接做 fp32 log-sum-exp（T3）。全部零初始化，由常數遮罩逐型別開關。

**G. Feynman–Kac 解碼（尺度三，新增；只在推論與產生訓練配對時使用）**
- K=4–8 個粒子批次生成；提議＝網路分佈乘上 token 局部的精確勢函數後重新歸一，被允許質量記為權重（F2）；在句界（由暫存器判定）且有效樣本數 < K/2 時重取樣。
- **約束自動機必須做可達性修剪**（實驗：只擋「立即違規」的天真遮罩有 64–71% 的回覆永遠收不了尾）。
- **前瞻扭轉用精確計算而非更多粒子**：以 bigram 代理模型對約束自動機做後向動態規劃，得到「由此狀態仍能達成約束的機率」表。實驗中它用單一粒子就把對真實條件分佈的偏離由 5.9 降到 0.4 nats；無扭轉時 32 個粒子仍剩 3.2 nats。帶雜訊的學習式扭轉可能比沒有更差（每步誤差 0.3 即劣於無扭轉）。
- 收尾是「滿足式」選擇而非對弱評分器取 argmax：先剔除失敗樣本（違反約束、偵測到迴圈、結構未關閉、長度出界），再在長度帶內取彼此最相似者（詞彙共識）。數學題取自洽多數。
- 評分頭（768→256→1，約 0.2M，掛在凍結的核心上，目標為 F3 的軟價值）只有在 E9 量到同題內相關 ρ≥0.3 時才啟用，並以扭轉比值進入。
- 同一套機制在訓練期用來產生偏好優化的配對（勝者／被剔除者）。

**H. 門控升級（預設關，E2 各跑一臂）**：Parallax 局部線性修正（0.6B 規模 −0.4%～−1.6%，依賴 Muon 類優化器）、selective attention、r=12、薄前奏對全迴圈。

## 5. 贏盲測的配方（依紅隊估計的勝率貢獻排序；對 Falcon、均衡題組）

| # | 做法 | 證據 | 估計貢獻 |
|---|---|---|---|
| 1 | **對話資料從第 0 步混入 25%**（smol-smoltalk、SmolTalk/MagPie-Ultra 多輪、Tulu-3 SFT、約束資料、PleIAs SYNTH 的 QA/RAG 格式），尾段改為對話為主 | Falcon：IFEval +9.3（偏好優化前）、+12.6（之後） | +5～+10 |
| 2 | **一個 epoch 的偏好優化**（lr 1e-6～3e-6）。配對來源：§4G 的粒子解碼（入選者對被剔除者）、精確驗證器標註、UltraFeedback、公開 reward model 評分（規則允許時） | Falcon 一輪 DPO：IFEval 50→66、AlpacaEval 勝率 2.96→9.43；超過 1 epoch 會退化 | +8～+20（相對只做 SFT） |
| 3 | **Feynman–Kac 解碼**（§4G） | 精確勢函數約 +2；剔除壞樣本 +2～+6（K≈4 即飽和）；加評分頭 +4～+5；評分器被鑽漏洞時 −3～−5，故採滿足式選擇 | +2～+6 |
| 4 | **精確輕量數學**（計算片段） | TinyGSM：125M 模型 GSM8K 63%；Falcon 19、MobileLLM 8 | 整體 +2～+5 |
| 5 | **從第 0 小時起的代理盲測**：400 題、兩個對手各用其最佳設定（主機 CPU 以 GGUF 執行）、評審左右對調並控制長度 | 5 個百分點的差異需約 800 次比較才看得出來 | 決定其餘各項的取捨 |
| 6 | **長度與格式策略**：先答後述；開放題 80–200 字、事實題 1–3 句 | 長度是人評偏好中係數最大的風格因子 | +2～+6 |
| 7 | **T=2048＋多輪** | 真實對話 41% 為多輪 | +1～+4 |
| 8 | **事後重標註的可驗證約束**（暫存器量出既有回覆的約 25 種性質，寫回提示） | CRAB、IFBench | +1～+2 |
| 9 | n-gram 計數頭、匯點與信心通道（§4A、§4C） | 硬接線 n-gram 頭 −6.7% 困惑度（340M）；短卷積 −2.1%（14.5M） | 損失 −1～−2%，勝率小幅 |
| 10 | 藏書（門控、精簡） | 紅隊中位 −0.6（樂觀 +4.7；常開 −6） | −1～+3 |

資料骨幹：ClimbMix 為主（nanochat 實測 −27% 算力），佐以 FineWeb-Edu 與維基文本。檢索感知訓練：預訓練 10–25% 序列帶藏書段落，其中 30–40% 只給干擾段，文件絕不檢索到自己，段落 token 損失權重 0.25，對話樣本至少一半不帶段落，並加入「找不到答案」樣本。優化器：參考實作的 MuonH 與「Muon＋NorMuon＋cautious weight decay」在代理模型上 A/B 後擇一。
