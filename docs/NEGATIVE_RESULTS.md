# 被否定或降級的候選

這份文件記錄在設計過程中認真推導、檢驗過，最後沒有採用的想法，以及否決的依據。數字來自對抗審稿、真實文本實驗（Simple English Wikipedia）與成本模型；可重跑的部分在 `tests/math/test_claims.py`。

## 1. 精確高斯過程注意力（「貝氏注意力」）

**想法。** 把 softmax 注意力（語境內的核平滑）換成高斯過程後驗均值；一次 Cholesky 分解給出所有前綴的後驗（`docs/MATH.md` B2），區塊版以「誘導點＋近期視窗」為支撐集。

**成立的部分。** 線性代數正確（誤差 1e-15）；它對重複出現的近似誘餌穩健（誘餌重複 64 次時正確率 0.95，匯點 softmax 0.64，一般 softmax 0）。

**否決的理由。**
- 公平的對照組是「softmax＋一個匯點」，後者本身就是精確的貝氏估計（B1）。在 Dirichlet–Markov 資料上兩者與貝氏預測的差距都 ≤2e-4 nats；先前量到的 0.43 nats 差距是對「沒有匯點的 softmax」量的。
- 文獻中同族方法（核嶺回歸、局部線性、遞迴最小平方）在 0.1–1.7B 規模的增益為損失的 0.1–1.6%。
- 真實文本上，它所能表達的收縮形式 n/(n+λ) 只比固定權重好 0.003–0.008 nats；語言需要的是冪律折扣（B4）。
- 取樣溫度 ≤0.8 時它讓重複迴圈更多，且成為吸收態（τ=0.6：63.6% 對 5.0%）。原因是精確貝氏預測會「認可」已出現的重複：重複 r 次後續抄機率為 (r+λ/V)/(r+λ)，溫度 <1 時逃脫機率的級數收斂。
- TPU 成本：XLA 內建的 Cholesky 展開要做約 800 倍於必要的工作；自寫兩層分塊版也要 softmax 頭的 4.5–9 倍，整體吞吐降 17–37%；bf16 單次乘法會讓 Schur 補矩陣失去正定。

**留下來的東西。** 匯點與信心通道（零成本）；n-gram 計數頭帶種類數 K；自我生成的證據降權。

## 2. 尺度遞迴迴圈

**想法。** 同一區塊跨尺度（token、片語、句）共享，粗尺度便宜所以多繞圈。

**結果。** 配置律 R_b ∝ (E_b/w_b)^{1/(1+αφ)} 成立，且 Hilberg 律（能量譜指數 β<1）確實意味著粗尺度應多繞圈；但 αφ≈0.1 使可約損失只降 0.1–3%。未採用。

## 4. 總結

在已量到的縮放律下（損失對有效參數量的指數約 −0.2），重排 20M 活躍參數的任何已知方式都只值個位數百分比。與對手的差距主要來自訓練算力（對手為 22–176 倍），能補的槓桿是資料配方、後訓練、解碼與精確工具。
